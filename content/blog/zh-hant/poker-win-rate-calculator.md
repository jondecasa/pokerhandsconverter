**贏率**是衡量你現金桌打得多好最清楚的單一數字。這個計算器把結果與手數換算成 **bb/100**、每 100 手的金額與**每小時收益**，並加上大多數玩家忽略的部分：一個 **95% 信賴區間**，告訴你這個數字有多少是實力、有多少仍然是運氣。

[calculator:winrate]

## 如何使用贏率計算器

- **淨結果：** 你贏或輸的金額。如果追蹤軟體已經以 bb 顯示，選擇**大盲**；否則選擇**金額**，並輸入你所打級別的大盲（NL50 為 0.50，NL100 為 1）。
- **已玩手數：** 樣本中的手數。
- **標準差：** PokerTracker 4 與 Hold'em Manager 3 會以 bb/100 顯示。如果你不知道，6-max 無限注德州撲克通常是 80–100；單挑和 PLO 更高。
- **每小時手數（選填）：** 所有牌桌合計，例如 4 桌 × 75 手 = 300。

## 贏率如何計算

```
bb/100 = 以大盲計的淨結果 / 手數 × 100
```

**例子。** 你在 40,000 手中贏了 1,500 bb：1,500 / 40,000 × 100 = **3.75 bb/100**。在 NL50 這是 $750，也就是每 100 手 $1.88。每小時 300 手時，3.75 × 3 = **每小時 11.25 bb（約 $5.60）**。

想更深入了解 bb/100 的意義以及不同級別之間如何比較，請見 [bb/100 詳解](/zh-hant/blog/bb-per-100-poker-win-rate-explained)。

## 信賴區間：你真的是贏家嗎？

從樣本測得的贏率只是你真實贏率的估計。計算器會在它周圍加上 95% 區間：

```
95% 區間 = bb/100 ± 1.96 × 標準差 / √(手數 / 100)
```

在這個例子中，標準差為 90：1.96 × 90 / √400 = 8.8，所以區間從 **−5.1 到 +12.6 bb/100**。它跨過了零，代表 40,000 手還無法證明你能贏這個遊戲。以相同的贏率，你大約需要 220,000 手，整個區間才會落在零以上。

這不是壞消息，而是正常的。[樣本量指南](/zh-hant/blog/sample-size-reliable-poker-stats)說明了贏率比 VPIP 這類數據收斂得慢多少，而[變異數計算器](/zh-hant/blog/poker-variance-calculator)則讓你看到兩位實力相同的玩家，結果可以差多遠。

## 怎樣的贏率算好？

線上無限注德州撲克現金桌的粗略參考：

| bb/100 | 通常代表 |
|---|---|
| 低於 0 | 輸錢，常常輸給抽水的不比輸給對手少 |
| 0–2 | 打平到小贏 |
| 2–5 | 穩定的贏家 |
| 5–10 | 強勢的贏家，多半在較低級別 |
| 高於 10 | 非常出色，或樣本仍然太小 |

級別越高贏率越低，而在微級別中，[抽水](/zh-hant/blog/what-is-rake-in-online-poker)佔了更大比例。在把你的數字和別人比較之前，先看看你的抽水與[返水](/zh-hant/blog/rakeback-and-your-bankroll)。

## 把贏率變成決定

- **資金：** 贏率相對於標準差越高，你需要的資金就越少。[變異數計算器](/zh-hant/blog/poker-variance-calculator)會算出你的破產風險，而我們的[資金管理指南](/zh-hant/blog/bankroll-management-online-cash-games)則說明何時升級與降級。
- **逐一檢查：** 贏率是上千個決定的總和。[EV 計算器](/zh-hant/blog/poker-ev-calculator)能幫你檢查單一的下注、詐唬與跟注。
- **選桌與選級別：** 決定加桌或升級是否值得的，是你的每小時收益，而不是 bb/100。

## 常見問題

**需要多少手牌才能得到準確的贏率？** 比大多數人想的多得多：標準差為 90 時，即使 100,000 手，區間仍約為 ±5.6 bb/100。

**應該使用全下調整後的贏率嗎？** 它去除了全下攤牌的運氣，所以比實際結果的雜訊少，但其餘的變異數仍然存在。

**為什麼我的每小時收益和 bb/100 差這麼多？** 每小時收益取決於你打多少手牌。只要 bb/100 不下降太多，加桌就能提高每小時收益。
