撲克中的每一個決定都有**期望值（EV）**：如果你把同一個打法重複上千次，平均會贏或輸多少。這個計算器處理最常見的兩種情況：**下注（或詐唬）**，以及**跟注**對手的下注。修改任何數字，結果都會即時更新。

[calculator:ev]

## 如何使用 EV 計算器

**下注或詐唬** 比較下注與過牌：

- **底池：** 你下注之前的底池。
- **你的下注：** 你投入的金額。
- **對手棄牌／加注：** 你預期對手棄牌或加注的頻率，其餘時間他們跟注。對手加注時，計算器假設你棄牌。
- **被跟注時你的勝率：** 面對會跟注的手牌，你在攤牌時獲勝的比例。純詐唬大約是 0%。
- **過牌時你的勝率：** 如果改為過牌，你預期能贏下目前底池的比例。

**跟注** 計算跟注是否有利可圖：

- **底池：** 桌上所有的籌碼，包含你面對的下注。
- **跟注金額** 以及你面對下注範圍時的**勝率**。

可以使用大盲或金額，只要所有數字使用相同單位即可。

## 下注的 EV 公式

你下注時可能發生三種情況，EV 就是每種結果乘以其發生頻率的總和：

```
EV(下注) = 棄牌% × 底池
         + 跟注% × (勝率 × (底池 + 2 × 下注) − 下注)
         − 加注% × 下注
```

對手棄牌時你贏下底池。對手跟注時，底池加上雙方的下注，你按勝率贏得其中一部分，再減去你投入的下注。對手加注而你棄牌時，你輸掉你的下注。

**例子。** 底池 100，你下注 75。對手 40% 棄牌、10% 加注、50% 跟注，被跟注時你有 30% 勝率：

- 棄牌：0.40 × 100 = **+40**
- 跟注：0.50 × (0.30 × 250 − 75) = **0**
- 加注：0.10 × −75 = **−7.5**

EV(下注) = **+32.5**。如果過牌能讓你贏下 100 底池的 35%，EV(過牌) = **+35**，所以這裡過牌稍微好一點。保持相同的頻率但改為下注 66，下注就以 **+35.2** 略為領先。下注大小與頻率的小改變都很重要，這就是為什麼值得把數字放進去算。

## 詐唬需要多常成功？

純詐唬（沒有勝率、從不被加注）在對手棄牌達到以下比例時損益兩平：

```
損益兩平棄牌率 = 下注 / (底池 + 下注)
```

| 下注大小 | 需要的棄牌率 |
|---|---|
| 1/3 底池 | 25% |
| 1/2 底池 | 33% |
| 2/3 底池 | 40% |
| 滿池 | 50% |
| 2 倍底池 | 67% |

把這些數字和對手的實際表現比較。[面對持續下注的棄牌率](/zh-hant/blog/fold-to-cbet-poker-stat-explained)偏高的玩家，會讓你的小額詐唬有很大優勢；很少棄牌的玩家，則會讓同樣的詐唬變成虧損的打法。[持續下注百分比](/zh-hant/blog/cbet-percentage-poker-stat-explained)說明了這場對抗的另一面。

## 跟注的 EV 與底池賠率

面對下注時，跟注的 EV 是：

```
EV(跟注) = 勝率 × (底池 + 跟注) − 跟注
```

當你的勝率等於**底池賠率**時損益兩平：

```
需要的勝率 = 跟注 / (底池 + 跟注)
```

**例子。** 底池 100，對手下注 50，所以底池是 150，你需要跟注 50。你需要 50 / 200 = **25%** 的勝率。在轉牌拿著同花聽牌（9 張 outs，約 20%），EV(跟注) = 0.20 × 200 − 50 = **−10**：只看直接賠率應該棄牌。

### 隱含賠率

如果你預期聽牌成功時能贏更多，聽牌仍然可以跟注。計算器會顯示**之後還需多贏多少才能損益兩平**：跟注 / 勝率 − 底池 − 跟注。在這個例子中，就是 50 / 0.20 − 200 = 河牌還要多贏 **50**。如果對手夠常付出這麼多，這個跟注就有利可圖。

## 實戰中的 EV

- **估計勝過猜測。** 你永遠不知道對手確切的棄牌率，但像面對持續下注的棄牌率或[面對 3-bet 的棄牌率](/zh-hant/blog/fold-to-3bet-poker-stat-explained)這類數據，能給你一個真實的起點。
- **EV 是長期的。** 一個 +EV 的詐唬仍然常常失敗。幾百手牌的結果說明不了什麼；[變異數計算器](/zh-hant/blog/poker-variance-calculator)會告訴你波動有多大。
- **追蹤你實際贏了多少。** 你的[贏率](/zh-hant/blog/poker-win-rate-calculator)是所有這些決定的總和，所以它是檢驗你的 EV 估計是否成立的最好方法。

## 常見問題

**撲克中的 +EV 是什麼意思？** 期望值為正的打法，在多次重複後平均會贏錢，即使這一次輸了。

**EV 和勝率一樣嗎？** 不一樣。勝率是你在攤牌時分到底池的比例；EV 還會計算你投入的籌碼以及對手棄牌的情況。

**怎樣的 EV 算好？** 任何正數都有利可圖，但要比較不同打法：最好的打法是 EV 最高的那一個，即使兩個打法都是正的。
